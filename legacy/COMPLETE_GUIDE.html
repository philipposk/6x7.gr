3. Setting Up GitHub

1 Create GitHub Account

  1. Go to: https://github.com
  2. Click "Sign up" (top right)
  3. Fill in:
    • Username: Choose a username
    • Email: Your email address
    • Password: Create a strong password
  4. Verify your email address

2 Create New Repository

  1. After logging in, click the "+" icon (top right)
  2. Select "New repository"
  3. Fill in repository details:
    • Repository name: 6x7.gr
    • Description: "My personal website" (optional)
    • Visibility: Select Public ⚠️ (Required for free hosting)
    • DO NOT check "Add a README file"
  4. Click "Create repository"
⚠️ Important: Repository must be Public for free hosting options!
✅ GitHub Repository Created!

4. Pushing Code to GitHub

1 Create GitHub Personal Access Token

  1. Go to GitHub.com → Your profile → Settings
  2. Scroll to "Developer settings" (left sidebar)
  3. Click "Personal access tokens" → "Tokens (classic)"
  4. Click "Generate new token" → "Generate new token (classic)"
  5. Name it: 6x7.gr website
  6. Check repo scope
  7. Click "Generate token"
  8. Copy the token immediately! (You won't see it again)

2 Initialize Git in Your Project

Open Terminal and run:

cd /Users/phktistakis/6x7.gr git init git add . git commit -m "Initial commit: Add website files"

3 Connect to GitHub and Push

git remote add origin https://github.com/YOUR_USERNAME/6x7.gr.git git branch -M main git push -u origin main

When prompted:

  • Username: Your GitHub username
  • Password: Paste your Personal Access Token (not your GitHub password!)
✅ Code Pushed to GitHub!
You can now see your files at: https://github.com/YOUR_USERNAME/6x7.gr

5. Setting Up Vercel

1 Sign Up for Vercel

  1. Go to: https://vercel.com
  2. Click "Sign Up"
  3. Recommended: Click "Continue with GitHub"
  4. Authorize Vercel to access your GitHub account

2 Import Your GitHub Repository

  1. Click "Add New..." → "Project"
  2. Find "6x7.gr" in your repositories
  3. Click "Import"

3 Configure Project Settings

Vercel will auto-detect settings. Verify:

  • Framework Preset: Other
  • Root Directory: ./
  • Build Command: Leave empty
  • Output Directory: Leave empty

Click "Deploy"

4 Wait for Deployment

Wait 30-60 seconds. When complete, you'll see your site URL:

✅ Site Deployed on Vercel!
Your site is now live at: https://6x7gr.vercel.app

6. Connecting Your Domain to Vercel

1 Add Domain in Vercel

  1. In Vercel dashboard, click your 6x7.gr project
  2. Click "Settings" tab → "Domains"
  3. In "Add Domain" field, type: 6x7.gr
  4. Click "Add"
  5. Vercel will show DNS records - Copy these values!

2 Add DNS Records in Papaki

  1. Go to papaki.gr and log in
  2. Click on 6x7.gr → "Manage Domain"
  3. Find "DNS Service" section
  4. Add A Record:
    • Type: A
    • Host: @ (or leave blank)
    • Value: 216.198.79.1 (from Vercel)
  5. Add CNAME Record:
    • Type: CNAME
    • Host: www
    • Value: 3919fac90518e646.vercel-dns-017.com. (from Vercel)
  6. Click "Save"

3 Verify DNS Records

  1. Go back to Vercel → Settings → Domains
  2. Click "Refresh" button
  3. Wait 5-60 minutes for DNS propagation
  4. Status should change to "Valid Configuration" ✅

4 Test Your Website

  1. Wait 5-60 minutes after adding DNS records
  2. Open a new browser window (or incognito mode)
  3. Visit: https://6x7.gr
  4. Your website should load! 🎉
✅ Domain Connected!

7. Troubleshooting

Problem: "This site can't be reached" / ERR_NAME_NOT_RESOLVED

Solution 1: Clear DNS Cache

sudo dscacheutil -flushcache sudo killall -HUP mDNSResponder

Solution 2: Change DNS Servers

  1. System Settings → Network
  2. Select connection → Details → DNS
  3. Add: 8.8.8.8 and 1.1.1.1
  4. Apply and restart browser

Solution 3: Wait Longer

New domains can take 2-4 hours to fully propagate. Be patient!

Problem: Vercel Shows "Invalid Configuration"

Check:

  • DNS records are added correctly in Papaki
  • Values match exactly what Vercel shows
  • Wait 5-60 minutes and click "Refresh" in Vercel
