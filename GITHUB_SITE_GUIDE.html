1. Install VS Code

1 Download VS Code

  1. Go to: https://code.visualstudio.com
  2. Click "Download for Mac" (or your operating system)
  3. Open the downloaded file
  4. Drag Visual Studio Code to your Applications folder

2 Open VS Code

  1. Open Applications folder
  2. Double-click Visual Studio Code
  3. VS Code will open
✅ VS Code Installed!

2. Create Your Website Files

1 Create Project Folder

  1. Open Finder
  2. Navigate to Desktop (or wherever you want)
  3. Create a new folder: Right-click → New Folder
  4. Name it: my-website (or any name you like)

2 Open Folder in VS Code

  1. Open VS Code
  2. Click File → Open Folder...
  3. Navigate to your my-website folder
  4. Click Open

3 Create index.html

  1. In VS Code, click the "New File" icon (or press Cmd+N)
  2. Save the file: File → Save As...
  3. Name it: index.html
  4. Add the HTML code (see guide for full code)

4 Create styles.css

  1. Create a new file: Click New File icon
  2. Save as: styles.css
  3. Add CSS styling (see guide for full code)

5 Create script.js

  1. Create a new file: Click New File icon
  2. Save as: script.js
  3. Add JavaScript code (see guide for full code)
✅ Website Files Created!
Your folder should contain: index.html, styles.css, script.js

3. Set Up GitHub

1 Create GitHub Account

  1. Go to: https://github.com
  2. Click "Sign up" (top right)
  3. Fill in:
    • Username: Choose a username
    • Email: Your email address
    • Password: Create a strong password
  4. Verify your email address (check your inbox)

2 Create New Repository

  1. After logging in, click the "+" icon (top right)
  2. Select "New repository"
  3. Fill in repository details:
    • Repository name: my-website
    • Description: "My personal website" (optional)
    • Visibility: Select Public ⚠️
    • DO NOT check "Add a README file"
  4. Click "Create repository"
⚠️ Important: Repository must be Public for free GitHub Pages!
✅ GitHub Repository Created!

4. Push Code to GitHub

1 Create GitHub Personal Access Token

  1. Go to GitHub.com → Your profile → Settings
  2. Scroll to "Developer settings" (left sidebar)
  3. Click "Personal access tokens" → "Tokens (classic)"
  4. Click "Generate new token" → "Generate new token (classic)"
  5. Name it: my-website
  6. Check repo scope
  7. Click "Generate token"
  8. Copy the token immediately! (You won't see it again)

2 Initialize Git in VS Code

In VS Code, open the Terminal (View → Terminal, or press Ctrl+`)

Run these commands:

git init git add . git commit -m "Initial commit: Add website files"

3 Connect to GitHub and Push

In Terminal, run:

git remote add origin https://github.com/YOUR_USERNAME/my-website.git git branch -M main git push -u origin main

When prompted:

  • Username: Your GitHub username
  • Password: Paste your Personal Access Token (not your GitHub password!)
✅ Code Pushed to GitHub!
You can now see your files at: https://github.com/YOUR_USERNAME/my-website

5. Enable GitHub Pages

1 Go to Repository Settings

  1. On GitHub, go to your repository
  2. Click the "Settings" tab (top menu)

2 Enable GitHub Pages

  1. Scroll down to "Pages" (left sidebar)
  2. Under "Source", select:
    • Branch: main
    • Folder: / (root)
  3. Click "Save"

3 Wait for Deployment

  1. Wait 1-2 minutes
  2. Refresh the page
  3. You'll see your site URL: https://YOUR_USERNAME.github.io/my-website
✅ GitHub Pages Enabled!

6. Your Site is Live!

Your Website URL

Your website is now live at:

https://YOUR_USERNAME.github.io/my-website

(Replace YOUR_USERNAME with your GitHub username and my-website with your repository name)

How to Update Your Website

  1. Edit files in VS Code
  2. Save your changes
  3. In Terminal, run:
git add . git commit -m "Updated website" git push
  • Wait 1-2 minutes - Your site updates automatically!

    • 7. Troubleshooting

    Problem: Can't push to GitHub

    Solution:

    • Make sure you're using Personal Access Token (not password)
    • Token must have repo scope checked

    Problem: GitHub Pages not working

    Check:

    • Repository is Public (not Private)
    • index.html is in the root folder
    • You selected main branch and / (root) folder
    • Wait 2-5 minutes after enabling

    Problem: Site shows 404 error

    Solution:

    • Make sure your repository name matches the URL
    • Check that index.html exists in the root
    • Wait a few more minutes for GitHub to build
